## Steps required to run the web app/site.
To see some of the features in action, here's a few things you can do.
1. Hover and click on the "Book now" button, when you hover it should change colour, and when you click on it it should take you directly to the booking section where you will see the booking form.
2. Use this information to complete the booking form:
    - Name: Jane Doe
    - Email: janedoe@gmail.com
    - Phone number: +44 123 456 7899
    - Adults: input **2**
    - Children: input **0**
    - Check-in: 20/02/2025
    - Check-out: 28/02/2025
    - Select Room Preference
    - Include Breakfast for £20?
    - Discount Code: input **WELCOME20**
3. Then click on *"Submit Booking"*
4. You should receive confirmation of your booking!
5. If you try to submit a booking without providing any information, the site will prompt you to select a room type.
