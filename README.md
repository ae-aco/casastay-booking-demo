# CasaStay Hotel Booking Web App

> I created a web app using html, css and javascript.

## Mock Scenario
The mock scenario for this project is a hotel web app, where the user can book from a selection of hotel rooms.

## Checklist for this project
- Input fields for user to provide personal and booking details
- Capture and store user input
- Add reusable functions to reduce repetition
- Use loops to simplify the code
- Use console.log and alert for feedback
- Add event driven changes 
- Use basic HTML and CSS styling

## How to test the web app
To see some of the features in action, here's a few things you can do.
1. Click "Book Now".
    - Hover changes color, click jumps to the booking form.
2. Use this information to complete the booking form:
    - Name: Jane Doe  
    - Email: janedoe@gmail.com  
    - Phone: +44 123 456 7899  
    - Adults: 2  
    - Children: 0  
    - Check-in: 20/02/2025  
    - Check-out: 28/02/2025  
    - Room Preference & Breakfast (£20)  
    - Discount Code: WELCOME20
3. Click *"Submit Booking"*
    - Confirmation alert pops up.
4. Submit a booking with empty fields.
    - You will be prompted to select a room.

## What I Learned
- The alert initially returned the booking confirmation with the price which adjusted accordingly when the discount code was used.
- Debugging JS can be tricky sometimes! Some features stopped working after some edits. Commented lines remain in code for reference. 
- I improved my problem solving skills by experimenting with edge cases e.g unavailable rooms, empty submissions.
